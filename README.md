# 🖼️ Pixel Gallery

A modern and responsive image gallery built using **HTML, CSS, and JavaScript**.

The project allows users to browse images by category, open images in a fullscreen lightbox, and navigate between images smoothly.

---

## 📌 Project Overview

**Pixel Gallery** is a frontend development project created as part of an internship task.

The main goal of this project is to demonstrate the use of:

- HTML for webpage structure
- CSS for responsive layouts and visual styling
- JavaScript for interactivity and image navigation

The gallery provides a clean and user-friendly way to explore different types of photography.

---

## ✨ Features

### 🖼️ Responsive Image Gallery

- Displays images in a clean grid layout
- Automatically adapts to different screen sizes
- Supports desktop, tablet, and mobile devices

### 🏷️ Image Categories

Images are divided into three categories:

- 🌿 Nature
- ✈️ Travel
- 🏛️ Architecture

Users can filter the gallery using category buttons.

### 🔍 Lightbox Image Viewer

Clicking an image opens it in a fullscreen lightbox.

The lightbox includes:

- Large image preview
- Image title
- Image category
- Image counter
- Previous and next navigation
- Close button

### ⏮️ Previous & Next Navigation

Users can navigate through images using:

- Previous button
- Next button
- Keyboard arrow keys

The gallery uses circular navigation, so moving past the last image returns to the first image.

### 🎞️ Image Preview Carousel

The lightbox displays the previous and next images partially on the sides of the current image.

This provides a carousel-style browsing experience.

### ✨ Hover Effects

Images include smooth hover effects and transitions to improve the visual experience.

### ⌨️ Keyboard Navigation

Keyboard controls are supported:

| Key | Action |
|---|---|
| `←` | Previous image |
| `→` | Next image |
| `ESC` | Close lightbox |

### 📱 Responsive Design

The gallery is designed to work across:

- Desktop
- Laptop
- Tablet
- Mobile

### ♿ Accessibility

The project includes basic accessibility features such as:

- Descriptive image `alt` text
- ARIA labels
- Keyboard navigation
- Focus-visible styles
- Accessible lightbox dialog
